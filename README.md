# ATELIER NOIR — Contemporary Luxury Apparel & E-Commerce Storefront

> **"The Architecture of Silhouette."**  
> *Autumn / Winter 2026 Collection • Paris / Tokyo / New York*

A contemporary luxury clothing brand e-commerce website featuring an interactive catalog, slide-over shopping bag, live currency switcher, interactive "Shop the Look" hotspots, quick-view product modal, size guide, and simulated checkout flow.

---

## ✨ Flagship E-Commerce Features

1. **Editorial Announcement Ticker & Currency Conversion**:
   - Rotating announcements on international shipping and seasonal drops.
   - Live multi-currency selector (`USD $`, `EUR €`, `GBP £`, `JPY ¥`) with real-time price conversion across all cards, quick-views, and cart totals.

2. **Full E-Commerce Product Catalog Engine**:
   - Filter by Department: *All Pieces, Outerwear, Knitwear, Tailoring, Footwear, Leather Objects*.
   - Filter by Gender: *All, Women, Men, Unisex*.
   - Sort by: *Featured Drops, Price: Low to High, Price: High to Low, Top Rated*.
   - Color Swatch Switching: Click any swatch on a product card to immediately change the garment view.
   - Dual Angle Hover: Hovering reveals alternate lookbook model angles.
   - Quick Size Add: Add a piece in sizes `XS` through `XL` directly from the product card without opening a new page.

3. **Interactive "Shop the Look" Lookbook Hotspots**:
   - Full-bleed styling editorial featuring pulsing hotspot pins on trench coats, trousers, tote bags, and boots.
   - Hover or tap any pin to view product details and launch instant checkout.

4. **Slide-Over Shopping Bag (Cart Drawer)**:
   - Dynamic Free Shipping Progress Meter (*"Add $35 more for Free Worldwide Express Delivery"*).
   - Quantity adjustments (`+` / `-`), size/color display, and removal.
   - Live Promo Code Engine: Test coupon code `ATELIER10` or `WELCOME10` for an immediate 10% discount calculation.

5. **Quick-View Product Modal**:
   - High-res zoom photography with interactive colorway swatches.
   - Composition, silhouette, and ethical mill details.
   - Stock counter (*"In Stock"* / *"Only 2 left"*).
   - Interactive size selection and Size Guide table.

6. **End-to-End Simulated Checkout Flow**:
   - Shipping details, payment method choice (Apple Pay, Credit Card, Klarna).
   - Encrypted order placement simulation with generated Order Reference ID (`AN-82941`).

7. **Interactive Wishlist Drawer**:
   - Heart-toggle on any card with live badge counter.
   - Slide-over drawer to review favorited garments with quick "Move to Bag" actions.

8. **Live Search Overlay**:
   - Instant search by title, fabric, silhouette, or category.

9. **Luxury Dark & Light Modes**:
   - Light: Warm Paper (`#F9F6F0`), Crisp Surface (`#FFFFFF`), Terracotta Cinnamon (`#B85D36`).
   - Dark: Deep Obsidian (`#0F1113`), Smoky Slate (`#181A1D`), Warm Amber Bronze (`#E07A5F`).

## 🚀 How to Run & Preview

### Option 1: Double-Click `dev.bat` (Windows)
Double-click `dev.bat` to launch the local development server and automatically open [http://localhost:3000](http://localhost:3000) in your browser.

### Option 2: Run via Node
```bash
node serve.js
```
Then navigate to [http://localhost:3000](http://localhost:3000).

### Option 3: Direct Browser Preview
Double-click [index.html](file:///c:/Users/HP-LAPTOP/.antigravity-ide/index.html) to open the complete storefront directly in Chrome, Edge, or Firefox.
